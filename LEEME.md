# infoboee - Periódico Parodia

Sitio web parodia y humorístico inspirado en la estética periodística digital moderna.

## 📁 Archivos creados
- `index.html`: Estructura principal con cabecera, cintillo de último momento, portada y modales interactivos.
- `style.css`: Estilos visuales con colores naranjas/oscuros, tipografías periodísticas (Roboto y Merriweather) y diseño responsivo para móviles.
- `noticias.js`: Archivo con la lista de noticias oficiales predeterminadas para editar directamente.
- `app.js`: Lógica interactiva para listar noticias, filtrar por categoría, publicar mediante el botón "+ Añadir Noticia" y leer notas completas.

## 🚀 Cómo publicarlo en Hostinger
1. Inicia sesión en la cuenta de **Hostinger** de tu amigo.
2. Ve a **Sitios Web** -> Administrar -> **Administrador de Archivos** (o File Manager).
3. Entra a la carpeta **`public_html`**.
4. Sube todos los archivos de esta carpeta (`index.html`, `style.css`, `noticias.js`, `app.js`).
5. ¡Listo! Al entrar al dominio de la página verán **infoboee** online.

## ✍️ Cómo agregar noticias fijas para que todos las vean
- Puedes abrir `noticias.js` y agregar nuevos bloques de noticias al array `defaultNews` con títulos cómicos entre amigos, o pedirme las ideas y te armo el archivo listo para copiar y pegar.
